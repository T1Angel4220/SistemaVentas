# Capturas de Pantalla

Esta carpeta debe contener todas las capturas de pantalla necesarias para el informe final de la APE7.

## 📸 Capturas Requeridas

### Instalación
- [ ] Instalación de Docker
- [ ] Instalación de Jenkins
- [ ] (Opcional) Instalación de Kubernetes

### Docker
- [ ] Construcción de imágenes (`docker build`)
- [ ] Imágenes creadas (`docker images`)
- [ ] Contenedores en ejecución (`docker ps` o `docker-compose ps`)
- [ ] Logs de contenedores
- [ ] Aplicación funcionando en navegador

### Jenkins
- [ ] Dashboard de Jenkins
- [ ] Job creado
- [ ] Pipeline en ejecución (vista clásica o Blue Ocean)
- [ ] Logs del pipeline
- [ ] Estado final del pipeline (Success/Failed)
- [ ] Historial de builds

### Kubernetes (Opcional)
- [ ] Pods en ejecución (`kubectl get pods`)
- [ ] Servicios creados (`kubectl get services`)
- [ ] Deployments (`kubectl get deployments`)
- [ ] Logs de pods
- [ ] Escalado de réplicas
- [ ] Aplicación funcionando después del despliegue

## 📝 Notas

- Nombrar las capturas de forma descriptiva (ej: `01-docker-images.png`)
- Incluir todas las capturas en el informe PDF final
- Asegurar que las capturas sean claras y legibles
